## 三个真实的坑，买之前先知道

**到期不续费，Office 会变成只读。** 这是订阅制最容易踩的地方。订阅失效后，Word、Excel、PowerPoint 还能打开、查看、打印已有文件，但不能再编辑，也不能新建。同时 1TB 的 OneDrive 会被压缩到一个很小的免费额度，超出的部分传不上去。有人把订阅当成买断用，第二年没续，发现文档改不了了。你要买的是一年的使用权，不是永久授权。

**授权绑在微软账号上，不跟设备走。** 换新电脑不用重新买，在新电脑登录同一个微软账号就行，记得把旧设备退出登录，免得占满 5 个名额。但账号本身不能转给别人用，也不能把这个订阅「过户」给朋友。

**低价档位要先分清是独立订阅还是拼车。** 如果你看到的那个特别便宜的价，实际是家庭组拼车，那你并不是订阅持有人，而是被组主拉进家庭组的成员。组主换人、组主自己退订，你这边立刻就不能用了，钱也不一定追得回来。同一家店里独立订阅和拼车的价差很大，别只看数字，看清楚你买的是哪一种。

退款这块，虚拟授权发货之后一般不支持无理由退，具体条款写在下单页，也可以先问客服再付钱。先买再问的顺序是反的。

## 常见问题

**Office 365 和 Microsoft 365 有什么区别？**
没有区别，是同一个订阅服务改了名字。你买到的应用还是 Word、Excel、PowerPoint 那一套。

**订阅到期后还能打开原来的文件吗？**
能打开、能看、能打印，不能编辑。续费之后恢复正常。

**换新电脑需要再买一次吗？**
不需要。在新电脑登录同一个微软账号，把旧设备退出登录，5 个名额里腾一个出来就行。

**家庭版能和朋友一起买吗？**
技术上可以组家庭组，但组主有权移除成员，你要接受这个风险。商用不行。

**Mac 和手机能用吗？**
能。PC、Mac、iPhone、iPad、安卓都支持，同一个账号登录即可。

**买错了能退吗？**
虚拟授权发货后一般不支持无理由退款，具体看下单页条款，拿不准就先问客服。
